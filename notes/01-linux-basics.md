# Основы Linux: Навигация и работа с файлами

## 1. Навигация и просмотр
* pwd (*Print Working Directory*) — показывает текущий полный путь к папке.
* ls (*List*) — выводит список файлов и папок в текущей директории.
* cd <путь> (*Change Directory*) — переход в указанную папку.

## 2. Создание файлов и папок
* mkdir <имя_папки> (*Make Directory*) — создать новую папку.
* touch <имя_файла> — создать пустой файл.
